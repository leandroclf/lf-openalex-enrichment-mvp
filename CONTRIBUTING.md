# Contributing (GitFlow obrigatório)

## Política para este repositório
Para qualquer mudança de código de produto:
1. Criar branch:       `feature/<issue>-<slug>`
2. Fazer commits pequenos e rastreáveis.
3. Abrir Pull Request para `main` com:
   - contexto da issue
   - evidência de testes
   - impacto esperado em KPI de valor
4. Solicitar revisão técnica do especialista responsável.
5. Fazer merge somente após aprovação.

## Não conformidade
- Push direto em `main` é não-conforme ao fluxo definido no workspace.
- Violações devem gerar ação corretiva no board operacional.
